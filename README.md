# InternLink

**InternLink** is a smart web application designed to connect fresh graduates and undergraduate students with internship opportunities relevant to their fields. Our platform bridges the gap between companies seeking young talent and students eager to gain real-world experience.

## 🔍 Project Overview

InternLink offers a streamlined platform where:
- **Students and graduates** can find and apply for internships tailored to their field of study.
- **Companies** can post internship vacancies and search for suitable candidates.
- A built-in **AI Assistant** helps users with career guidance, skill recommendations, and general internship-related queries.
- A **CV Generator** feature enables students to easily create professional resumes.

## ✨ Key Features

- 🔎 **Internship Search & Apply** – Filter and find internships by category, location, and more.
- 🧠 **AI Assistant** – Ask about career paths, skill development, or how to improve your profile using natural language.
- 📄 **CV Generator** – Instantly generate a well-structured CV based on your profile and experience.
- 🏢 **Company Portal** – Post internships, manage applicants, and find ideal candidates.
- 👤 **User Accounts** – Separate dashboards for interns and companies.

## 🧠 AI & Architecture

- **Language**: Python
- **AI Framework**: Integrated with AI features using **Retrieval-Augmented Generation (RAG)** architecture for more context-aware responses.
- **Data Retrieval**: Relevant knowledge base and context are dynamically retrieved to improve AI interaction quality.
